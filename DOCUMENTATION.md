# Портфолио Aliaksandr Kavaliou

Сайт собран как витрина front-end практики для компаний. Тексты, даты, стек и контакты взяты из CV `CV_Aliaksandr_Kavaliou.html`. Цифры, которых в CV нет — оценки PageSpeed, ссылки на магазины клиентов, проценты владения навыками — на сайт не добавлялись.

## Что это за сайт

Одностраничный сайт без сборки и без фреймворка: HTML, CSS и JavaScript. Его можно открыть доменом `portfolio` в OpenServer, потому что точка входа — `index.html` в корне проекта.

Язык страницы по умолчанию зависит от браузера. Если язык браузера начинается с `ru`, открывается русская версия. Иначе — английская: CV и аудитория компаний англоязычные. Выбор EN / RU запоминается в `localStorage` под ключом `portfolio-lang`. Без JavaScript остаётся английская вёрстка, все проекты видны, фильтр и переключатель языка не работают.

## Файлы

- `index.html` — разметка, английские тексты, контакты, JSON-LD с именем, должностью, почтой, телефоном и LinkedIn.
- `css/styles.css` — сетка, типографика, карточки, список проектов, адаптив.
- `js/main.js` — русские строки, переключение языка, фильтр проектов, меню на узком экране.
- `favicon.svg` — метка AK.
- `DOCUMENTATION.md` — этот файл.

Шрифт Manrope подключается с Google Fonts и поддерживает кириллицу. Если он не загрузится, остаётся Segoe UI.

Визуально страница светлая и карточная: первый экран без крупной антиквы, избранная работа Herbano на широком экране идёт полосой со снимком слева, остальные четыре — сеткой. Список проектов — отдельные карточки, описание обрезается до двух строк. Фильтры и годы прилипают под шапкой, пока открыт список. Ссылки на магазины по-прежнему не стоят.

## Фильтр

Кнопки делят список на непересекающиеся группы: Magento (11), Shopware (7), React (2), Symfony (3), Laravel (1), WordPress (1), Другое (4). В «Другое» попадают Babylonpark, Wines Direct, Beautyhub и Brigadi: в CV у них нет Magento, Shopware, React, Symfony, Laravel или WordPress как платформы проекта.

Счётчик показывает, сколько строк видно, и меняет слово «проект / проекта / проектов» и `project / projects`. Пустые годы скрываются. Если категория пустая, появляется строка «В этой категории ничего нет». Выбранный фильтр пишется в адрес как `?stack=magento` (и аналогично для остальных). `all` параметр убирает.

## Поведение интерфейса

- Шапка липкая. После прокрутки у неё появляется нижняя линия.
- На ширине до 760px разделы прячутся за кнопкой «Меню». Escape и клик по ссылке меню закрывают.
- Текущий раздел в меню отмечается через `IntersectionObserver`.
- Ссылки ведут к `#work`, `#ledger`, `#skills`, `#about`, `#contact`.
- Анимация карточек отключается при `prefers-reduced-motion: reduce`.

Атрибут `hidden` в авторских стилях принудительно даёт `display: none`, иначе правила `display: grid` и `display: inline-flex` перебивали бы скрытие строк и годов.

## Как обновить содержание

Новый проект добавляется в `index.html` статьёй `.ledger-row` с `data-tags` из списка фильтра и английским текстом. Русский перевод даты и описания кладётся в объект `ru` в `js/main.js` с теми же ключами `data-i18n`. Если проект должен попасть в избранное, для него нужна ещё карточка `.case`. Число `29` на первом экране и текст «29 projects» правятся вручную: счётчик фильтра считает только строки списка.

## Проверка

Синтаксис `js/main.js` проверен через `node --check`. Отдельно сверены ключи `data-i18n` со словарём, число строк списка (29), допустимые `data-tags`, уникальность `id` и баланс скобок в CSS. Браузер не открывался.
